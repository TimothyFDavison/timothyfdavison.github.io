# Personal Website

Creating this site (timothyfdavison.com) to experiment with static site generation/ website hosting, and more 
broadly to share side projects when I produce them. 

See the results at https://www.timothyfdavison.com. 

Site produced using Jekyll and the Whiteglass template. 

### Running Locally
On a Mac, 
```bash
brew install ruby
gem install --user-install bundler jekyll
bundle install
bundle exec jekyll serve
```
